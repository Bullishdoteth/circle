Circle is a modern platform that helps communities collect contributions, manage shared funds, and automate payouts with complete transparency.

## ✨ Features

- Create and manage savings circles
- Invite and manage members
- Dedicated virtual accounts for contributions
- Automatic payment reconciliation
- Contribution tracking and reporting
- Secure payouts
- Real-time activity dashboard

## 🛠️ Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- shadcn/ui
- Clerk Authentication
- Drizzle ORM
- PostgreSQL
- Nomba APIs

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/circle.git

cd circle

npm install

npm run dev
````

Open **http://localhost:3000** to view the application.
